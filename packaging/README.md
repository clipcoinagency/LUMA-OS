# Packaging (Phase 8)

Wraps the real app (`dist/index.html`, built by `npm run build` at the repo root) for each
platform. Distinct from `poc/`, which only ever wrapped the Phase 0 storage prototype
(`poc/web/index.html`) to validate that the toolchains work at all.

| Directory | Platform | What it produces |
|---|---|---|
| `browser-edition/` | Windows, macOS | `Life OS.html` — `dist/index.html` copied via `npm run package:browser`. No install, opens in the default browser. |
| `android/` | Android | Capacitor 8 shell (`webDir` → `../../dist`) → a debug/release APK, built in CI (`.github/workflows/app-android.yml`) since this machine has no Android SDK. |
| `desktop-tauri/` | Windows, macOS | Tauri 2 shell (`frontendDist` → `../../../dist`) → NSIS installer / universal `.dmg`, built in CI (`.github/workflows/app-desktop.yml`) since this machine has no Rust toolchain. **Not shipped until code-signed/notarized** — see `docs/PHASE-0-ARCHITECTURE.md` §5 (Smart App Control hard-blocks unsigned `.exe`s). |
| `assets/icon-1024.png` | Android, desktop | Source icon for `tauri icon` / Capacitor, regenerated by `npm run icons` (`scripts/make-icons.mjs`) alongside the PoC's copy — one generator, two consumers, never edited by hand. |

## The one piece of platform-specific app code

`src/lib/platform/platform.ts` is the only file with per-platform branches (Phase 0 decision — see
architecture doc §4.1's adapter table). The single-file build can't inline the Capacitor
Filesystem/Share bridge (it's native glue specific to the Android shell), so `android/bridge-src.js`
is bundled separately by `npm run bridge` into a sibling `dist/native-capacitor.js`, and
`saveTextFile()` loads it on demand the first time a save is attempted on Capacitor — proven by
`tests/e2e/capacitor-bridge.mjs` against the real built app. Tauri needs no such step: its
`window.__TAURI__` bridge is injected into the webview before any page script runs.

## Building locally vs CI

Only the browser edition can be produced on this machine (no Android SDK, no Rust toolchain — same
finding as Phase 0). Android and desktop builds run in GitHub Actions and are downloaded from the
Actions tab as artifacts, exactly like the Phase 0 PoC builds.
